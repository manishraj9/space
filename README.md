# 🚀 Space – Interactive Space Exploration Website

An immersive **space-themed interactive web experience** built using modern frontend technologies. The project features engaging animations, responsive layouts, and a visually appealing interface inspired by space exploration.

> ⚠️ This project is created for learning, frontend development practice, and portfolio demonstration.

# 🚀 Installation

```bash
git clone https://github.com/manishraj9/space.git

cd space

npm install

npm run dev
```

Open:

```
http://localhost:5173
```
